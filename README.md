🍕 Pizza Sales Analysis using SQL

This project focuses on analyzing pizza sales data using SQL to extract meaningful business insights. The dataset includes multiple related tables such as orders, order_details, pizzas, and pizza_types.

Through this project, various SQL concepts like joins, aggregation, grouping, subqueries, and window functions are applied to solve real-world business problems.

🔍 Key Insights:
• Top-selling pizzas
• Revenue analysis
• Daily and cumulative sales trends
• Category-wise contribution
• Order distribution by time

📌 This project demonstrates how raw data can be transformed into actionable insights using SQL, helping businesses make data-driven decisions.
